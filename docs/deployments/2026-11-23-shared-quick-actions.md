# 승인된 공통 고정 버튼 — 2026-11-23

사용자가 PC·모바일 미리보기를 확인하고 “이대로 전체 적용”으로 승인했습니다.

- PC: 오른쪽 검은색 세로 메뉴에 관심고객등록 / 카카오톡 / TOP.
- 모바일(600px 이하): 카카오톡 아이콘 / TOP 두 개만 표시.
- 기존 노란색 카카오톡, 단독 TOP, 하단 전화상담·문의하기 고정 바는 숨겨 중복을 방지합니다. 본문/상단 연락처는 유지합니다.
- 관심고객등록은 현장별 해당 접수 위치로 이동합니다. GD는 기존 인라인 접수, 메인 홈페이지는 기존 등록 모달을 엽니다.
- 카카오톡은 기존 채널 URL을 사용합니다. 고객 정보를 자동 제출하지 않습니다.
- 키보드가 올라오면 새 메뉴를 숨기며, 키보드 접근성·감소된 모션 설정을 지원합니다.
- 서초 PH1603 독립사이트는 사용자의 “독립사이트는 그대로 두기” 답변에 따라 변경하지 않았습니다.

## 수정 원본과 배포

UI의 수정 원본은 `outputs/portal/quick-actions.js`입니다. `node scripts/build-quick-actions.mjs`를 실행하면 공통 `lead-form.js`의 생성 구간에 포함됩니다. 기존 접수 처리 코드를 수정하지 않습니다. 공통 파일을 불러오는 메인·현장·전용 주소·GD 전용 사이트에 함께 적용됩니다.

이 작업에서는 실제 운영 원본을 백업하고 ETag 조건부 쓰기로 73개 HTML의 스크립트 버전을 갱신했습니다. 본문 전체를 오래된 GitHub 사본으로 덮어쓰지 않았습니다. GitHub HTML에는 기존 GitHub 내용에 같은 버전 변경만 적용했고, 이번 요청으로 수정한 브라이튼/르웨스트 등의 최신 변경을 함께 반영했습니다.

GD의 HTML 변경은 공용 스크립트 URL의 캐시 버전에 한정됩니다. GD 내용 원본이나 도메인은 바꾸지 않았으며, 이후 GD 배포가 운영 변경으로 오인해 중단하지 않도록 실제 새 객체 해시를 `sites/gdmetro/deployed-hashes.json`에 반영합니다.

## 함께 완료한 수정

브라이튼 전용 주소는 `https://brighten.bunyang-alimi.com/`입니다. 잘못 작성한 `brighton.bunyang-alimi.com`은 올바른 주소로 301 이동하며 매개변수와 경로를 보존합니다. 메인 현장 링크·canonical·사이트맵도 수정했습니다.

마곡 롯데캐슬 르웨스트의 “한눈에 보기” 제목은 모바일에서 한 줄로 표시합니다. 기존 정보를 숫자 카드, 핵심 정보 표, 6개 아이콘 카드, 10개 타입 표로 정리했습니다. 기존 접수 양식은 보존했습니다.
