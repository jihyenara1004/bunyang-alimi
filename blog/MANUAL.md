# 블로그 세트 매뉴얼 (대표님이 "블로그 써줘"라고 하면 이 기준으로 한 번에 만든다)

대표님은 같은 요청을 다시 말하지 않기를 원합니다. "OOO 블로그 써줘" 한마디면 아래 **5가지를 한 세트**로 만들어 드립니다.

## 세트 구성
1. **블로그 글**: 띄어쓰기 포함 약 1,700자(표·제목·태그 제외 본문 기준), 블로그체(~습니다). 인사말은 "안녕하세요, 리치메이커입니다." (블로그명은 리치메이커, "분양알리미" 문구 쓰지 않음)
   - 소제목은 "~다"로 끝내지 말고 명사형으로 간결하게
   - **사업개요는 표**로 (글 안 표 + 선 있는 표 이미지 `00-사업개요표.png`, 네이버에 표를 붙이면 선이 사라지기 때문)
   - 제목 후보 3개, 태그는 **100자 이내**
   - 글 끝에 **분양알리미 홈페이지 해당 현장 주소**를 "더 알아보기" 링크로 (예: `https://bunyang-alimi.com/현장id/`, 현장 id는 `outputs/portal/properties.js`의 id)
   - 문의: 대표번호 1688-5650 (현장 공식 번호는 쓰지 않음). 단, **직접 맡지 않은 대장 단지**(예: 디에이치 반포124)는 `AI-작업-인수인계.md` 규칙대로 전화번호·분양 주체 오해 표현을 빼고 "분양 주체·시행사 아님" 고지
   - 일정·금액은 확정/예정/전망을 구분하고 기준일을 적는다. 출처가 있는 수치만 쓴다
2. **사진 약 10장**: 파일명 `현장-01~10-설명.jpg`, 가로 1000px, 우하단 "리치메이커 1688-5650"과 중앙 옅은 "리치메이커" 워터마크(유사문서 방지). 글의 어느 위치에 넣을지 표로 안내
   - 사진 출처: 저장소 `outputs/portal/assets/`에 있는 현장 이미지, 조감도·투시도·내부·커뮤니티 위주. 포스터형 이미지는 사진 부분만 잘라 쓴다(여백 제거로 영역 탐지)
   - 공식 사이트 이미지는 이 환경에서 파일로 내려받을 수 없을 때가 많음(핫링크만 가능) → 대표님이 저장해 주시면 사용
3. **문의 배너** 1200×315: 빨간 수화기 아이콘 + "현장명 24시간 문의 환영" + "문의: 1688-5650", 건물 그림 없음
4. **썸네일** 1000×1000: 정사각형, 글자는 가운데 안전영역(좌우 110px, 상하 150px) 안에, "분양알리미" 문구 없이 맨 아래에 대표번호
5. **홈페이지 주소**: 위 링크. 현장 상세페이지가 없으면 먼저 만들 것인지 확인

## 전달 방식
- **ChatGPT 전달용 글은 `블로그글/` 폴더의 `00-지시사항.md` 기준**으로 코드블록 하나(일반 텍스트)로 정리해 드린다. 글은 `블로그글/날짜_주제_GPT전달용.txt`로 저장.
- 글은 Claude 문서(Docs)로 만들어 링크 제공, 이미지는 파일로 전송(압축 파일 1개 + 개별 미리보기)
- 직접 만든 이미지 코드: `blog/tools/render-thumb-banner.js`, `render-table.js` (playwright + Noto Sans CJK, 배경 이미지는 base64로)
