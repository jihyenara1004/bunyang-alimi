# 블로그 작성 매뉴얼 (분양알리미 · 리치메이커)

GPT와 Claude가 블로그 글·썸네일·배너를 항상 같은 방식으로 만들도록 정리한 기준서입니다.
기준 예시: `blog/examples/brighten/` (브라이튼 여의도, 2026-10-31)
마지막 갱신: 2026-10-31 (Claude)

## 0. 기본 정보 (바꾸지 말 것)
- 글쓴이 소개: "안녕하세요, 리치메이커입니다." (블로그는 리치메이커 이름으로 운영. "분양알리미"는 쓰지 않음)
- 대표번호: **1688-5650** (모든 썸네일·배너·글 끝에 이 번호만 사용. 개인 번호는 쓰지 않음)
- 포털 주소: https://bunyang-alimi.com
- 현장 상세페이지 주소는 해당 페이지의 **canonical 주소**를 쓴다.
  - 예) 브라이튼 여의도: `https://bunyang-alimi.com/brighten/` (`/brighton/`도 있으나 대표 주소는 brighten)
  - 주소는 `<현장폴더>/index.html`의 `rel="canonical"` 값으로 확인한다. 포털을 열 수 없으면 사용자에게 묻는다.
- 답변은 한국어, 사용자는 "대표님"으로 부른다. 불필요한 사용량을 줄이는 쪽으로 진행한다.

## 1. 글 작성 규칙
1. **분량**: 띄어쓰기를 뺀 글자 수 2,500자 이상(기본 2,500~2,800자). 쓴 뒤 반드시 글자 수를 세어 확인한다. (`''.join(t.split())` 길이)
2. **제목**: 짧고 간결하게(15~25자). 현장명 + 핵심 키워드 하나. 예) "반포 다음은 여의도, 브라이튼 여의도"
3. **구성**(기본 틀)
   1. 인사 한 줄 + 오늘 주제 소개
   2. 시장 배경(최근 기사·실거래가 근거)
   3. 지역 개발·호재 현황
   4. 현실적인 단점·유의점(입주 시기, 규제 등) — 균형을 위해 반드시 포함
   5. 현장 소개(규모·시공·준공·입지·교통)
   6. 지금 주목하는 이유 (3가지 정도)
   7. 구매 전 확인할 점(대출·세금·자금계획)
   8. 타입과 조건 안내
   9. 마무리 + 문의 안내 + 더 알아보기 링크 + 대표번호 + 배너
   10. 면책 문구
   - **소제목(목차)은 간결하게**: "~습니다/~다"로 끝내지 않고 명사형으로 짧게 쓴다. 예) "1. 서울 5호선 김포 연장", "4. 단지 개요", "구매 전 체크포인트", "6. 타입·조건", "마무리"
4. **근거**: 시세·개발 현황은 반드시 웹 검색으로 최신 기사를 확인해서 쓴다. 기억에 의존하지 않는다. 날짜(월)와 출처 기준임을 글에 밝힌다. 기사 문장을 그대로 베끼지 않고 풀어서 쓴다.
5. **광고 표현 주의**: "오른다", "수익 보장", "무조건" 같은 단정 표현 금지. "기대", "전망", "평가도 있다"로 쓴다. 글 맨 끝에 아래 면책 문구를 넣는다.
   > ※ 본 글의 시세와 개발 현황은 언론 보도 기준이며, 시장 상황과 행정 절차에 따라 달라질 수 있습니다. 투자 수익을 보장하지 않습니다.
6. **링크**: "▶ ○○ 더 알아보기" 문구 + 상세페이지 주소를 **본문 중간(현장 소개 뒤) 1번, 글 맨 끝 1번** 넣는다.
7. **끝부분 순서**(고정)
   ```
   현장 방문과 호실별 가격 상담이 필요하시면 편하게 문의 주세요. 24시간 문의 환영합니다.

   ▶ ○○ 상세정보 더 알아보기
   (상세페이지 주소)

   📞 대표번호 1688-5650

   [문의 배너 이미지]

   ※ 면책 문구
   ```
8. 가격은 호실표 기준으로만 쓰고, 최신 가격은 상담으로 안내한다. 호실표 가격이 바뀌었을 수 있으니 확실하지 않으면 타입(평형)만 쓴다.
9. 글은 **텍스트로만** 보여 주고(블로그에 붙여넣기용), 이미지 자리는 `[썸네일 이미지]`, `[문의 배너 이미지]`로 표시한다.

## 2. 썸네일 규칙 (1000×1000 정사각형)
- 네이버 블로그 목록에서 글자가 잘리지 않도록 **글자는 가운데 안전영역** 안에 둔다. (과천 한양수자인 썸네일이 잘렸던 경험 반영)
- 구성: 큰 제목 2줄(강조 단어는 핑크) → 현장명 → 금색 구분선 → 부제 → **맨 아래 "대표번호 1688-5650"(골드)**
- **"분양알리미" 문구는 넣지 않는다.**
- 색: 네이비 그라데이션 바탕 + 골드 테두리·포인트 + 핑크 강조
- 생성: `python3 -I blog/make_images.py "현장명" "ENGLISH NAME" "제목1줄" "강조단어" "부제" 출력폴더`
- 현장 사진을 배경으로 쓰는 버전은 사용자가 사진을 주었을 때만 만든다.

## 3. 문의 배너 규칙 (1200×315)
- 왼쪽: 영문 현장명(골드, 작게) / 한글 현장명(흰색, 크게) / **"24시간 문의 환영"**(핑크) / "현장 방문 · 호실별 가격 상담"
- 오른쪽: 빨간 원 안 흰 수화기 아이콘 + "대표번호" + **1688-5650**
- 건물 그림은 넣지 않는다. 같은 스크립트가 썸네일과 함께 만든다.
- 예전 단순형(흰 바탕, 빨간 수화기 + "문의: 번호")도 필요하면 요청 시 만든다.

## 4. 이미지 사용 규칙 (유사이미지 방지)
네이버는 이미 올라온 이미지와 같거나 비슷한 이미지를 알아본다. 교육자료·조감도·평면도를 쓸 때:
1. **자르고 크기·비율을 바꾼다** (가로형 → 정사각형 등)
2. **워터마크**: 오른쪽 아래 "리치메이커 1688-5650" + 가운데 연한 대각선 "리치메이커". `blog/make_photos.py` 사용. 크기에 맞춰 우측 하단 + 중앙 연한 대각선.
3. 설명 글자("브라이튼 여의도 47평" 등)를 이미지에 넣거나 색 배경·테두리를 둘러준다.
4. 2~3장을 합쳐 새 이미지로 만든다.
5. 밝기·색감은 보조로만 조정한다.
6. **평면도는 좌우반전 금지**(실제와 달라 고객이 오해함).
7. 같은 현장 글이 여러 편이면 글 내용도 서로 다르게 쓴다(이미지만 바꾸면 유사문서가 될 수 있음).
8. 교육자료는 시행사 자료이므로 외부 게시 가능 범위를 현장에 확인하도록 안내한다.

## 5. 작업 순서 (매번 이 순서로)
1. 현장 자료 확인(포털 `work/property-catalog.json`, 교육자료 PDF, 호실표)
2. 웹 검색으로 최신 시장·개발 기사 확인
3. 글 작성 → 글자 수 확인(2,500자↑) → 사용자에게 텍스트 전달
4. 제목 후보를 요청받으면 4개 정도 제시(검색어가 들어간 안을 추천)
5. 썸네일·배너 생성(`make_images.py`) → 이미지를 직접 열어 글자 잘림·번호 확인 후 전달
6. 사용자가 올린 뒤 수정 요청이 오면 같은 파일을 고쳐 다시 전달
