# 블로그글 폴더 지시사항 (대표님 기준)

대표님은 Claude가 쓴 블로그 글을 **ChatGPT에게 복사해 전달**하고, 네이버 블로그 게시는 ChatGPT가 합니다.
글을 쓸 때마다 이 폴더에 저장하고, 아래 기준을 지킵니다. 세트 구성(사진·배너·썸네일)의 세부 기준은 `../blog/MANUAL.md`를 따릅니다.

## 1. 전달 방식 (가장 중요)
- 새 글을 쓰면 **ChatGPT에게 복사할 수 있는 코드블록 하나**로 묶어서 드린다. 설명·잡담은 코드블록 밖에 둔다.
- 코드블록 안은 **마크다운 기호(**, ##, |표| 등) 없이 일반 텍스트**로 쓴다. 표는 "항목 : 내용" 줄 형식으로 쓰고, 선 있는 표 이미지는 별도 요청 시 제공한다.
- 코드블록 맨 위에 ChatGPT에게 줄 작업 지시문(네이버 게시 방법, 사진 위치 등)을 붙인다.
- 같은 내용을 이 폴더에 `날짜_주제_GPT전달용.txt`로 저장한다.

## 2. 글 기준
- 블로그명 리치메이커. 인사말 "안녕하세요, 리치메이커입니다." ("분양알리미" 문구 쓰지 않음)
- 문체 ~습니다, 소제목은 명사형으로 간결하게(~다로 끝내지 않음)
- 본문 띄어쓰기 포함 약 1,700자, 사업개요는 표(항목 : 내용)
- 제목 후보, 태그는 **100자 이내**
- 문의는 대표번호 **1688-5650** (24시간 문의 환영), 끝에 "더 알아보기" 홈페이지 주소
- 수치는 출처 있는 것만, 확정·예정·전망 구분, 금액은 기준일 표기

## 3. 현장별 표기 규칙
- **인시그니아반포**: "인시그니아"만 단독으로 쓰지 않는다. 광고·블로그에서는 항상 **"사평대로12 건물명 인시그니아반포"**로 표기한다. (제목·본문·태그 모두 적용, 띄어쓰기 없이 "인시그니아반포")
- 상가(인시그니아반포): 통매각 가능, 병원·음식점·담배권 편의점 업종 언급, 상가 분양가는 올려서 표기하고 "회사 보유분 금액 협의 가능"을 붙인다. (금액 숫자는 대표님이 주신 것만 사용)
- 담배권은 호실별 지정 가능 여부가 다르므로 "확인해 드립니다" 식으로 쓴다.
